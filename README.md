# 족보-강의자료 선지 매칭 포털 (과목별 & 권한 관리 & 오르조 기출문제집 시스템)

> **강의 자료(PDF, PPTX, Word)와 족보 문항을 과목별로 분리 관리하고, 선지별 강의 출처를 정밀 대조할 뿐만 아니라 태블릿 수험 앱 '오르조(Orzo)'처럼 기출문제를 실전처럼 풀고 채점하며 강의 슬라이드로 즉시 오답노트를 복습할 수 있는 올인원 학습 시스템입니다.**

---

## 🌐 사이트 접속 및 기본 계정 안내

### 1. 👥 이용자 포털 (User Portal)
- **접속 주소**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **기본 테스트 계정**:
  - **아이디**: `user1`
  - **비밀번호**: `user1234!`
- **신규 이용자**: 로그인 창의 **[이용 승인 신청]** 탭에서 이름/아이디/비밀번호를 입력하여 신청서를 제출하면 관리자의 승인 후 로그인할 수 있습니다.
- **비밀번호 변경**: 상단 헤더의 **[비밀번호 변경]** 버튼을 통해 언제든 본인 계정 비밀번호를 변경할 수 있습니다.

### 2. 🛡️ 관리자 콘솔 (Admin Console)
- **접속 주소**: [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)
- **관리자 마스터 계정**:
  - **아이디**: `admin`
  - **비밀번호**: `admin2026!`
- **관리자 전용 기능**:
  - 🔔 **가입 신청자 승인/거절**: 신청자 목록 확인 후 원클릭 `[승인]` / `[거절]`
  - 👥 **이용자 관리 및 비밀번호 재설정**: 승인된 이용자 권한 정지/삭제 및 이용자 비밀번호 직접 재설정
  - 📚 **과목(강좌) 개설 및 관리**: 과목 추가(예: "생명과학", "일반물리학"), 수정, 삭제
  - 🔐 **관리자 비밀번호 변경**: 관리자 마스터 비밀번호 변경

## 🌟 핵심 기능 소개

### 1. 📱 오르조(Orzo) 스타일 기출 문제집 & 실전 풀이 모드 (NEW!)
- **기출 문제집 서재**: 업로드된 족보들이 세련된 문제집 카드 형태로 자동 바인딩됩니다.
- **인터랙티브 실전 풀이**:
  - 오르조 스타일의 깔끔한 문제 뷰어 (문제 발문, 선지 ①~⑤ 마킹 인터페이스)
  - 실시간 타이머 및 문항별 이동 네비게이션
  - **OMR 빠른 답안 마킹 표**: 푼 문제/안 푼 문제를 한눈에 확인하고 즉시 문항 점프
  - **💡 실시간 강의자료 힌트**: 문제 풀이 중 선지와 연관된 강의 슬라이드 힌트 확인 가능
- **원클릭 자동 채점 & 심층 오답노트**:
  - 시험 제출 즉시 점수(100점 만점), 소요 시간, 정답률 산출
  - **오답노트 킬러 기능**: 각 선지가 **어느 강의 자료의 몇 번 슬라이드/페이지에서 출제되었는지 원문과 형광펜 하이라이트**로 바로 확인하여 완벽한 복습 가능!
- **정답표(Answer Key) 관리**: 문제집별로 정답 번호를 간편하게 등록 및 수정할 수 있습니다.

### 2. 📚 과목(Subject)별 독립 분리 관리
- 상단 네이비 바에서 현재 과목을 선택하면 강의 자료, 족보, 문제집, 풀이 기록이 과목별로 완전 격리되어 체계적으로 관리됩니다.

### 3. 🔍 선지-강의자료 정밀 대조 및 엑셀 다운로드
- 족보 선지(①~⑤)를 강의 슬라이드/페이지와 형태소, TF-IDF, 구문 매칭으로 대조
- 🟢 확실한 언급, 🟡 관련 내용, ⚪ 직접 언급 없음 상태 판정
- 엑셀(.xlsx) 파일로 1클릭 다운로드 제공

### 4. 🔐 비밀번호 변경 및 보안 관리
- **이용자**: 상단 헤더 [비밀번호 변경] 버튼으로 안전하게 변경
- **관리자**: 관리자 콘솔 [보안 설정] 탭에서 마스터 비밀번호 변경 및 개별 이용자 비밀번호 재설정 지원
